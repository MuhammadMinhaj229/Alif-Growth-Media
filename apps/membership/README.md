## Purpose & Scope
Member management and fee cycle automation for gyms, academies, and membership businesses. Tracks attendance, active packages, overdue fees, and dispatches automated WhatsApp reminder links.

## Key Features
- Automated WhatsApp renewal reminders before plans expire
- Member attendance, active passes, and payment receipts
- 1-tap WhatsApp reminder link generation
